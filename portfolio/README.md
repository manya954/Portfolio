# Manya Sinha — Personal Portfolio

Built with Next.js 14, React, TypeScript and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a new GitHub repo and push this folder to it.
2. Go to https://vercel.com/new, import the repo, and click Deploy (default Next.js settings).

All content lives in `app/page.tsx` (skills, projects, publications, milestones arrays at the top).
